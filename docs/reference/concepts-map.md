| Area | Objects | Steps |
|------|---------|-------|
| Workloads | Pod, Deployment, ReplicaSet, StatefulSet, Job, CronJob | 0.3, 1.2, 7.1, 7.4 |
| Config | ConfigMap, Secret, env, volumes | 1.1, 2.3–2.4, 3.2 |
| Networking | Service, Endpoints, DNS, Ingress, NetworkPolicy | 1.4, 4.1, 6.4 |
| Storage | PV, PVC, StorageClass | 1.2, 7.4 |
| Security | RBAC, SA, RoleBinding, Pod Security, TLS, encryption | 4.2, 6.1–6.3 |
| Ops | Probes, resources, HPA, PDB, rollouts, events | 2.5–2.6, 7.1–7.3 |
| IaC | Helm charts, releases, values, dependencies | 1.2, 5.1–5.2, 8.1 |
